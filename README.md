# Se Auto Service — сайт автосервиса в Казани

Статический сайт-визитка автосервиса **Se Auto Service** (Гвардейская ул., 54/3, Казань).
Свёрстан на чистом HTML/CSS/JS, без сборщиков и фреймворков.

## Источник данных

Весь контент — только из карточки организации на Яндекс Картах:
<https://yandex.ru/maps/org/se_auto_service/106544069364/>

- 15 услуг и цен — из вкладки «Товары и услуги» (обновлено 9 ноября);
- 52 отзыва — реальные тексты клиентов (у всех оценка 5);
- 8 фотографий — из альбома организации;
- рейтинг 5,0 (56 оценок), адрес, график 09:00–19:00, особенности и марки авто.

Позиции, у которых в карточке стоит цена `1 ₽`, на сайте показаны как «по запросу» —
об этом есть сноска под прайсом. Фактические цены не выдумывались.

## Структура

```
index.html            — вся страница (семантические секции, JSON-LD AutoRepair)
css/fonts.css         — @font-face для Tektur и Inter (только latin + cyrillic)
css/style.css         — дизайн-система: токены, сетки, адаптив
js/main.js            — меню, Motion-анимации, слайдер отзывов, лайтбокс
assets/fonts/*.woff2  — самохостинг шрифтов
img/opt/*.webp        — оптимизированные фото из альбома
img/opt/og.jpg        — обложка для соцсетей
data/                 — исходные данные карточки (отзывы, прайс, список фото)
```

## Дизайн

- Заголовки — **Tektur** (кириллица проверена рендером), текст — **Inter**.
- Телефоны — системный шрифт (`-apple-system / Segoe UI / Roboto`), без обводок.
- Палитра: тёплая бумага `#f1f1ee`, графит `#101114`, электрик-синий `#2440ee`.
- Референс: <https://ru.pinterest.com/pin/1004232416945489329/> — светлая
  воздушная композиция, парящая шапка-пилюля, крупная типографика, карточки,
  тёмная полоса и круглые кнопки-стрелки.
- Анимации — Motion (vanilla, CDN) с уважением к `prefers-reduced-motion`;
  без CDN сайт остаётся полностью читаемым.

## Мобильная версия

- У фиксированной шапки на мобиле **отключён** `backdrop-filter` — иначе она
  становится containing block и ломает `position: fixed` у панели меню.
- Бургер справа (`margin-left: auto`), z-index выше панели; номер телефона —
  внутри панели меню.
- Фото в герое поднято сразу под H1, прайс — в одну колонку, работы — компактным
  списком в две колонки.

## Локальный запуск

```bash
python3 -m http.server 8000
# http://localhost:8000
```
